01
Package

CodeGraph

Maps your whole codebase so AI assistants understand how files connect.

Why: It uses Tree-sitter, a real code parser, instead of AI calls, so indexing is fast and predictable.

Best for: projects big enough that your AI assistant keeps losing track of files.

02
Package

Graphify

Builds a map of your code, images and documents for your AI assistant.

Why: Genuinely helpful context, but it spends API tokens, so the bill grows with project size.

Best for: small projects. For big codebases, CodeGraph is the cheaper choice.

Use it small projects only See in toolkit
03
Tool

ManimCat

Turns plain-language requests into math animations.

Why: It checks and auto-fixes generated Python before running it, which is clever. But each output takes 15 to 90 seconds, and it depends on Redis and Bull, which makes serverless hosting hard.

Best for: trying locally for fun. Not ready to build a product on yet.

Wait See in toolkit
04
Library

RAG-Anything

Ask questions over PDFs, images, tables and formulas together.

Why: Powerful, but it's a heavy framework built on LightRAG and MinerU, not a simple building block. Beginners will get lost.

Best for: after you've built a plain text RAG app and understand how it works.

Wait See in toolkit
05
Tool

Anti-detect browsers

Modified browsers that hide automation from websites' bot checks.

Why: They're trending with AI agents, but their main job is getting around website protections. That easily breaks a site's terms of service.

Instead: use official APIs, or test browser automation on your own site.

Skip
